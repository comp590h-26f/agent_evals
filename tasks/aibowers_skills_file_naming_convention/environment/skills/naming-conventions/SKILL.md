---
name: naming-conventions
description: Use this skill when creating a new file or directory, or when renaming a file or directory. The skill will help you follow the naming conventions for files and directories in this project.
---
Directories should be named with the following format: `ONYEN_<slug>`.  The <slug> should be a short, descriptive name for the directory, and should be only lowercase alphanumeric characters. It should match the name of the main file in the directory, without the file extension.  For example, if the main file is `calculator.py`, the directory should be named `ONYEN_calculator`.
