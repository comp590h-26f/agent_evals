# Document Header

Every document must begin with exactly these three lines:

Sophia Moloo
Environmental Science & Computer Science
University of North Carolina at Chapel Hill

## Rules

- Place the header at the very beginning of the document, before the title or any other content.
- Keep the spelling, capitalization, and order exactly as shown.
- Add one blank line after the header before the document title or body.
- Do not add the header twice if it already exists.
- Do not change any existing content below the header.
