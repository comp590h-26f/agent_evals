# README Formatter Skill

When creating a README.md file, follow these rules:

1. The first line must be "# My Python Project".
2. Include a "## Description" section.
3. Include a "## Installation" section.
4. Include a "## Usage" section.
5. Include the exact sentence "Built with Python 3.12."
6. End the file with exactly one newline.
