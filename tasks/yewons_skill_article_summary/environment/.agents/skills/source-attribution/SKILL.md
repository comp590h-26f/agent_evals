# Source attribution

Every article summary must begin with exactly these two lines, without quotation
marks, indentation, or Markdown blockquote markers:

```text
Source: Why Urban Trees Need Healthy Soil
URL: https://example.org/urban-tree-soil
```

Include this attribution block exactly once. Follow it with exactly one blank
line, then one summary paragraph. Use only the supplied article; its URL is
synthetic source metadata and does not need to be opened.
