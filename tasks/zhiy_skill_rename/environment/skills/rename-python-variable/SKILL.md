# Rename a Python variable

Our team generates new variable names instead of choosing them by hand.

1. From this skill's directory, run `python scripts/new_name.py <current_name>`.
2. Use the printed name exactly as the new name.
3. Update every use of the variable, and leave the code's behavior unchanged.
